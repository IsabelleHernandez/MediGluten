# MediGluten

## About
MediGluten is a website designed to help users investigate whether medications contain gluten-related ingredients.

## Technologies
- HTML
- CSS
- JavaScript
- Python

## Pages
- Home
- Search Medicines
- Medication Results
- Saved Medicines

## Project Goals
- Create a user-friendly medication search website.
- Retrieve reliable medication ingredient information.
- Use AI to help analyze ingredients.
- Display sources and gluten-related assessments.
- Allow users to save medications.

## Collaboration
All team members are using GitHub to share code and communicate changes.
